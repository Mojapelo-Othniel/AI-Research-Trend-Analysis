# AI Research Trend Analysis

## Project Overview
This project develops a prototype system for analysing AI research publications. It uses machine learning and natural language processing techniques to classify research abstracts and identify emerging research topics.

## Project Objectives
- Classify research abstracts using machine learning.
- Preprocess research articles using NLP techniques.
- Summarise research articles.
- Identify research topics using Latent Dirichlet Allocation (LDA).
- Visualise topic distributions using pyLDAvis.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- NLTK
- Matplotlib
- Seaborn
- Gradio
- Gensim / pyLDAvis
- Jupyter Notebook

## Repository Structure
- `documentation/` – Documentation for Questions 1–4.
- `datasets/` – Project datasets and research articles.
- `notebooks/` – Jupyter Notebooks containing the analysis for Questions 1–4.
- `deployment/` – Deployment design and supporting files for Questions 1 and 2.

## Project Questions
- **Question 1:** Initial data analysis and research abstract classification.
- **Question 2:** Model comparison, optimisation and prototype deployment.
- **Question 3:** Research article preprocessing and summarisation.
- **Question 4:** LDA topic modelling and interactive topic visualisation.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebooks folder.
4. Run the notebooks in order, from Question 1 to Question 4.
